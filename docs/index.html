⌚ Nike+ SportWatch GPS — get your runs back

Your runs are still on the watch

Nike's servers are gone, but the watch kept your runs in memory. Plug it in, read it, and download each run as a GPX file for Strava, Garmin Connect or any mapping app.

🔒 Everything happens in this browser tab: your runs are never uploaded anywhere. Only map backgrounds are downloaded from OpenStreetMap.

Do not connect the watch to Nike+ Connect. That software erases the watch after "uploading" it to servers that no longer exist. This page only reads.
  1. Put the watch on its USB dock and plug the dock into this computer.
  2. Click the button below, pick “Nike+ SportWatch” in the list, and click “Connect”.
  3. Wait a few seconds while the watch is read (twice, to check the copy).

This browser cannot talk to USB devices. Use Chrome or Edge on a computer — or open a file saved earlier.

You can also drop a .packets file (from pull_raw_data_v2.py) anywhere on this page.

Everything the page sent to and received from the watch. If something goes wrong, attach it to an issue on the GitHub repository. It contains no GPS position.

    Questions
    
    
    The watch does not appear in the list
    Check that the dock is plugged in and the watch sits properly on it, then try another USB port. Close Nike+ Connect if it is running: it keeps the watch busy. On Linux, the browser needs permission to access the device (a udev rule for vendor 11ac, product 5455).
    
    
    Which browsers work?
    Chrome, Edge, Opera and other Chromium-based browsers on a computer (Windows, macOS, Linux). Firefox and Safari do not support talking to USB devices from a web page.
    
    
    The date of a run looks wrong
    The watch clock can drift or be wrong. For runs with GPS, the date comes from the GPS and is reliable; without GPS, only the watch clock is available.
    
    
    Heart rate and steps are missing
    Those formats are not decoded yet: no heart-rate strap or foot pod was paired on the watch used to build this tool. If you have runs with them, please get in touch on GitHub.
    
    
    Is it safe for the watch?
    Yes: reading only sends the read command, nothing is erased or written, and you can read the watch as often as you like. Only two actions write to the watch, and only when you click them: setting its clock, and emptying it (after a backup).
